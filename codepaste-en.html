CodePaste Privacy Policy

Effective date: 2026-01-19
Contact: yaogdu@gmail.com

CodePaste is a clipboard history and code utility for developers. To provide clipboard history, search, and paste, the app reads the system clipboard. Data is processed and stored locally by default. If you enable iCloud sync, your data is synced across your devices via iCloud.

Data We Process

  • Clipboard content: text, code, links, images, file paths, colors.
  • Entry metadata: source app name, timestamps, tags, pin/favorite status.
  • Optional AI metadata: summaries and vector index (generated and stored locally).

How We Use Data

  • Provide clipboard history, search, filters, paste, and preview.
  • Perform formatting/transforms and IDE actions based on user settings.
  • Sync history across devices when iCloud sync is enabled.

Data Sharing

CodePaste does not sell or share your clipboard content with third parties. If iCloud sync is enabled, your data is synced via Apple iCloud between your devices.

Permissions

  • Accessibility/Input Monitoring: for global hotkeys and active app context.
  • Automation: to interact with IDEs and open files/projects (user approval required).
  • File access: to preview or open files you select.

Apple Intelligence

Apple Intelligence features are experimental and can be disabled in Settings. These features are available only on supported devices, and summaries/semantic indexes are generated and stored locally.

Data Retention

You can set retention periods in the app and clear all history or cached files at any time.

Changes

We may update this policy and publish the latest version on this page.
