CodePaste User Guide

Contact: yaogdu@gmail.com

CodePaste is a clipboard history and code utility for developers. Copy anything and it appears in your history. Use the global hotkey to open the overlay, search, and paste into the active app.

Quick Start

  • Default hotkey: ⌘⇧V to show/hide the overlay (customizable in Settings).
  • Type in the search field to find items instantly (FTS full‑text search).
  • Use arrow keys to select, press Enter to paste.
  • Press Space to preview images or files.

Keyboard Shortcuts

  • ⌘⇧V: Show/Hide the overlay.
  • ⌘F: Focus the search field.
  • Esc: Clear search if not empty; otherwise close the overlay.
  • ↑ / ↓: Move selection.
  • Enter: Paste selected item.
  • Space: Preview image/file items.
  • ⌘C: Copy selected item to clipboard.

Search & Filters

  • Search supports keywords across your clipboard history.
  • Filters include: All, Pinned, Favorites, Code, Text, Link, File, Image, Color.

Menu Bar

  • Show Clipboard / Hide Clipboard.
  • Settings…
  • Quit CodePaste.

Organize

  • Pin or favorite frequently used items.
  • Add up to 3 tags for quick retrieval.
  • Multi‑select with ⌘, range‑select with ⇧.

Context Menu

  • Copy/Paste as Plain Text.
  • Copy as Markdown Pro
  • Format Code / Transforms Pro
  • Preview (images/files).
  • Open file/project in IDE (permission required) Pro
  • Show in Finder (files/images).
  • Copy color values (HEX / RGB / SwiftUI).
  • Edit content, edit tags, or delete an item.

Settings

  • Customize global hotkey and language.
  • Set retention period, clear history or cached files.
  • Choose paste destination and plain‑text paste.
  • Adjust file cache limit Pro

Pro Features

Labs

Permissions
