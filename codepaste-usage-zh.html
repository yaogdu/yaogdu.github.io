CodePaste 使用说明

联系方式：yaogdu@gmail.com

CodePaste 是面向开发者的剪贴板历史与代码工具。复制后即可在应用中看到记录， 使用全局快捷键呼出悬浮窗，快速搜索并回贴到当前应用。

快速开始

  • 默认快捷键：⌘⇧V 呼出/隐藏悬浮窗，可在设置中修改。
  • 直接输入关键词即可搜索历史记录（FTS 全文检索）。
  • 方向键选择条目，按 Enter 回贴到当前应用。
  • 按 Space 快速预览图片或文件。

快捷键

  • ⌘⇧V：打开/关闭悬浮窗。
  • ⌘F：聚焦搜索框。
  • Esc：搜索有内容时清空搜索；无内容时关闭悬浮窗。
  • ↑ / ↓：切换选中条目。
  • Enter：粘贴选中条目。
  • Space：预览图片/文件条目。
  • ⌘C：复制选中条目到剪贴板。

搜索与筛选

  • 顶部搜索框支持关键词搜索。
  • 筛选按钮支持：全部、置顶、收藏、代码、文本、链接、文件、图片、颜色。

菜单栏（状态栏）

  • 显示剪贴板 / 隐藏剪贴板。
  • 设置…
  • 退出 CodePaste。

组织与管理

  • 置顶 / 收藏：常用内容快速固定。
  • 标签：最多 3 个标签，用于快速检索。
  • 多选：按住 ⌘ 点击可多选，按住 ⇧ 可连续选择。

右键菜单

  • 复制为纯文本 / 粘贴为纯文本。
  • 复制为 Markdown Pro
  • 格式化代码 / 转换工具 Pro
  • 预览（图片/文件）。
  • 在 IDE 中打开文件/项目（需授权） Pro
  • 在 Finder 中显示（文件/图片）。
  • 复制颜色（HEX / RGB / SwiftUI）。
  • 编辑内容、编辑标签、删除条目。

设置项

  • 修改全局快捷键与外观语言。
  • 设置数据保留时长、清空全部历史或缓存文件。
  • 选择粘贴目标与纯文本粘贴。
  • 调整文件缓存上限 Pro

Pro 功能

  • iCloud 同步 Pro
  • IDE 联动打开项目/文件 Pro
  • 代码格式化与转换工具集 Pro
  • 复制为 Markdown Pro
  • 文件缓存上限可调 Pro
  • 自定义黑名单 Pro

实验室功能

  • Apple Intelligence 摘要与语义搜索（可关闭，需兼容设备）。

权限说明

  • 辅助功能/输入监控：用于全局快捷键与获取当前应用上下文。
  • 自动化：用于与 IDE 交互并打开文件/项目（需用户授权）。
  • 文件访问授权：用于预览或打开用户选择的文件。
